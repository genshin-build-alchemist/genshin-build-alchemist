# 빌드 카드 (FR-06, 데이터 담당)

1. _template.json 을 복사해서 캐릭터키.json 으로 저장 (예: albedo.json)
2. 캐릭터·무기·성유물 이름은 data/characters_ko.json, data/items_ko.json 과 똑같이
3. 외부 가이드는 참고·링크만, 내용은 직접 요약 (복사·크롤링 금지)
4. checked_version 에는 내용을 확인한 게임 버전 (예: 7.1)
5. 검사: 프로젝트 루트에서 python3 -m core.validate

이름이 _ 로 시작하는 파일은 양식이라 챗봇이 읽지 않습니다.
