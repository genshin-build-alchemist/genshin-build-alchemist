```

<color=#FFD780FF>강공격</color>

회전 종료 시 추가로 한 번 더 강력하게 휘두른다.

<color=#FFD780FF>낙하 공격</color>

### 무기 효과 (자리표시자)

전:
```
치명타 피해가 <color=#99FFFFFF>{0}</color> 증가한다. 생명의 계약 수치 증가 시, 장착 캐릭터가 주는 피해가 <color=#99FFFFFF>{1}</color> 증가한다. 해당 효과 지속 시간: 6초, 최대 중첩수: 3회
```
후:
```
사면 (5성 한손검)
기초 공격력: 48 / 주옵션: 치명타 피해 9.6%
효과 「죽음의 계약」(1재련): 치명타 피해가 20% 증가한다. 생명의 계약 수치 증가 시, 장착 캐릭터가 주는 피해가 16% 증가한다. 해당 효과 지속 시간: 6초, 최대 중첩수: 3회
모든 것을 버렸던 사기꾼이 사용한 레이피어. 당시에 그는 이 검을 신분 위장용 도구로 사용했다
```

```

```

다른 세계에서 건너온 여행자. 신에 의해 가족을 빼앗긴 뒤 일곱 신을 찾는 여정에 오른다
```
